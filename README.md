
# Cloud Guardian

A serverless IoT Security Monitoring system built on AWS.

## Project Overview
Cloud Guardian simulates smart security sensors (motion + temperature).
It detects anomalies, stores events, and sends alerts using a fully serverless architecture.

## Tech Stack
- **AWS Lambda** (Python)
- **API Gateway**
- **DynamoDB**
- **SNS** (for alerts)
- **S3 + CloudFront** (frontend)
- **AWS SAM** (Infrastructure as Code)
